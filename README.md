A token launch radar that ranks pre-token protocols by momentum breakout value: it scores every protocol in the sealed snapshot with the momentum breakout model, writes the ranked board, and gives each protocol a concrete farm plan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
